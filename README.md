# PACK//DEPTH

スマホ縦持ち前提の「バックパック整理 × ローグライク × 恒久成長」ゲーム試作版。

- 10階層ダンジョン
- 死亡時に装備はロスト、獲得XPは持ち帰り
- XPで恒久スキルツリーを強化
- 5×5（強化で最大6×6）のバックパック
- 形の違う装備をドラッグ・回転して配置
- 隣接シナジー（毒・電池・雷撃コイルなど）
- 自動戦闘
- 5階に中ボス、10階にボス
- 画像アセット不使用。キャラクター・敵・アイテム・背景はCanvas/CSSでコード生成
- 主人公スプライトは128×128のオフスクリーンCanvasへ実描画
- localStorageで恒久XP・スキル・最高到達階を保存

## 起動

静的サイトなので `index.html` をそのまま配信すれば動作します。
